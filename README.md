# Dijkstra Shortest Path Algorithm (Python)

## Overview
This project implements Dijkstra’s shortest path algorithm in Python to calculate the shortest path between nodes in a weighted graph.

The implementation applies graph traversal and optimization concepts using Python data structures and priority queues.

## Features
- Weighted graph traversal
- Shortest distance calculation
- Path reconstruction
- Priority queue implementation using `heapq`

## Technologies Used
- Python
- Jupyter Notebook
- heapq

## Concepts Applied
- Graph algorithms
- Data structures
- Path optimization
- Algorithm analysis

## Sample Applications
- Navigation systems
- Network routing
- Logistics optimization
- Pathfinding problems
